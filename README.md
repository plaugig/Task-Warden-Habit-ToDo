# TaskWarden 🛡️

TaskWarden — это масштабируемое Android-приложение для управления задачами и отслеживания привычек. В отличие от стандартных To-Do трекеров, проект делает упор на геймификацию рутины для повышения вовлеченности пользователя.

Проект разработан с упором на современную Android-разработку, строгую архитектуру и реактивный UI.

## 🛠 Технологический стек (Tech Stack)
* **Язык:** Kotlin
* **UI:** Jetpack Compose
* **Архитектура:** Clean Architecture (Data, Domain, Presentation слои), MVI / MVVM
* **Асинхронность:** Coroutines, Kotlin Flow (StateFlow, SharedFlow)
* **Локальная БД:** Room Database
* **Dependency Injection:** Hilt
* **Инструменты:** Git, Gradle (Kotlin DSL)

## 🚀 Функционал (Features)
* **Управление задачами (To-Do):** Создание, редактирование и трекинг ежедневных задач.
* **Трекер привычек:** Формирование рутины с отслеживанием прогресса (streak).
* **Система геймификации (🚧 В активной разработке):**
  * Интерактивный виртуальный питомец (кот), состояние которого (сытость, настроение) напрямую зависит от выполнения привычек и задач пользователя.
  * Виртуальный ассистент (робот), который динамически реагирует на пропущенные дедлайны и мотивирует пользователя закрывать таски.

## 🏗 Архитектурные решения
Проект спроектирован по канонам **Clean Architecture** для обеспечения тестируемости и масштабируемости:
1. **Domain Layer:** Содержит чистую бизнес-логику (UseCases), абстрагирован от любых Android-зависимостей.
2. **Data Layer:** Реализация репозиториев, локальное кэширование через Room, маппинг DTO/Entity в доменные модели.
3. **Presentation Layer:** Полностью реактивный UI на Jetpack Compose. Управление состояниями экранов реализовано через однонаправленный поток данных (UDF).
